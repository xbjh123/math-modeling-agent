## 核心任务
把 Actor-Critic 精炼出的方案**展开为可执行的数学规格书**。不做公理化深度推导——只把模型写清楚到"代码能直接照着实现"。

## 规格书必备三块
1. **符号表**：区分状态变量 / 决策变量 / 外生参数 / 随机误差项，每个符号给物理含义与量纲。
2. **闭式目标函数**：完整写出目标函数（含符号、下标、取值范围），不用抽象记号。
3. **关键假设**：列出模型成立的前提假设，标注哪些是题面明示、哪些是合理简化。

## 纪律（2024A 教训回灌，最高优先级）
- **判据溯源强制**：每个"终止判据 / 约束触发条件 / 目标达成定义"必须引用题面原文语句作依据（注明第几问），并解释原文语义到数学判据的映射；题面可作多种解读时，列出全部候选判据逐一分析并给出选择理由。禁止用"等价于""即"悄悄替换题面判据——2024A 曾把"不能继续盘入（碰撞）"误读为"尾巴到达中心（几何到达）"，整问答案尽失。
- **量纲单位**：cm/m、万元/元等换算常数显式写入符号表。
- **理论性质必须尝试**：对每个核心对象尝试证明至少一条理论性质（不变性 / 单调性 / 上下界 / 唯一性）——人工优秀论文普遍含此类证明（如板凳龙"调头曲线长度不变"）；确实无法证明时，显式写明"已尝试 X 与 Y 两条路径，因……不适用"，禁止静默跳过。
- **先精确归约、再采样离散**（2025A 对比 A196 回灌）：判据需要对几何体离散采样时，先尝试利用凸性/对称性把"逐点判定"归约为"有限特征判定"（范例：圆柱全遮蔽可由球凸性归约为只检查上、下底面两个圆周——A196 定理，使判定从采样近似变为精确且计算量减半）；归约不成再做采样，并按命题 2 报告采样收敛方向与误差估计。
- 仍不做：公理化推导、KKT、凸性判定——除非硬核题要求。
