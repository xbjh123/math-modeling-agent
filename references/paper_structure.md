# 论文结构蓝图规范（paper_blueprint 格式定义）

> 2026-08-29 重做论文编写层时新增。
> 用途：定义 `blueprints/paper_blueprint.md` 的固定格式，作为写作层（chapter_writer）的装配图。
> 核心思想：把"论文必须有什么"从 chapter_writer 的一行提示词，变成**写作前必须产出的结构化清单**，并用结构审校层（paper_structural_reviewer）硬性校验其兑现度。

---

## 1. 为什么需要蓝图

对比国奖论文后，我方在**写作层**的三处差距全部来自"结构性缺失"，而非"写不好"：
- **每问结果后缺"策略规律提炼"段**——从最优解回提炼可迁移规律，是国奖标志性写法；
- **缺参考文献节**——领域文献 2-4 条 + AI 工具使用披露（易成硬伤）；
- **缺"精确归约"型定理**——把采样近似变成精确判定，计算量减半（国奖论文的典型理论亮点）。

这三处，靠 chapter_writer 提示词里写"必须有"是不够的——写作时容易临时忘记。**蓝图把"必须有什么"提前固化成一份装配图**：写作前先填蓝图，写作时逐段对照蓝图填，写完后由结构审校层逐项核对蓝图是否被兑现。

## 2. 蓝图文件位置与命名

```
<workdir>/.modeling/manuscript/blueprints/paper_blueprint.md
```
（与 `modeling_report.md`、`sections/*.tex` 同级，归入 manuscript 产物树。）

## 3. 蓝图固定结构（六块）

### 3.1 全篇结构（章节树）
列出整篇论文的章节装配：
- 生成前：按题目问题数 X 生成 `01_intro_assump` → `02_problem1` → … → `(X+1)_problemX` → `(X+2)_sensitivity_conclusion` 的完整树。
- 每章标题预填（如"一、问题重述"、"三、问题一模型：…"、"八、模型检验"）。
- **编号约定**：主节用"一、二、…"，子节用"3.1 / 3.1.1"；章节树须明确各章对应的标题与编号，供模板 `\input` 按序装配。

### 3.2 每问标准子结构（核心，固定模板）
每个问题章必须包含以下子结构，缺一不可：

```
<问题 N> 章（章节树中的 problemN）
├── [模型]     本问用什么模型，闭式目标函数（引用规格书），关键假设
├── [求解]     实际算法/求解器、参数、是否收敛；多起点/种子数
├── [结果]     关键数字表 + 一句话解读（数字含义，不是数字堆砌）
├── [策略规律] 从最优解回提炼可迁移的规律  ← 国奖后回灌，必填
├── [亮点]     本问值得强调的一点
├── [判据示意] 几何/机理类题 ≥1 幅判据示意图（先直观后公式）；纯评价/预测类可空
└── [配图]     本问必配图种清单（从 references/figure_catalog.md 勾选）
                       必含要素：场景俯视图/判据机理图等；概念示意类须标"非真实比例"
```

**每个子结构必须有内容；任何子结构为空，在蓝图中标红 `【待补】`，不得跳过。**
策略规律段范例句式："最优方案的关键对象位于……处，微小的调整是对……的精细修正。"（从数值解回提炼对一般情形的指导，非复述数值。）

**配图席（`[配图]`）说明**：从 `references/figure_catalog.md` 勾选本问必配图种（几何/机理/调度题必配"场景俯视图 + 判据机理图"），每幅列出必含要素。绘图统一走 `scripts/fig_helpers.py` + `references/paper_figures.md` 配色，几何/数值图必须用求解引擎的真实数据（不臆造坐标），概念示意标注"非真实比例"。缺图/撞色/要素缺 → 结构审校回退。

### 3.3 参考文献席（占位，禁用编造）
写作层不自行编造文献。蓝图预留席位，来源由主线程（联网检索+人工核验）填入：
```
[文献1] （待主线程检索+核验）领域期刊/教材，支持模型选型（如相关领域综述、所用水法/算法的基础文献）
[文献2] （待主线程检索+核验）
...
[AI 工具] 按竞赛规则披露 AI 工具使用（名称/环节/作用），禁止编造
```
写作时若有真实文献则填入，无则由主线程补充，**未经核验不得引用**。

### 3.4 定理/命题清单（归约类性质）
收集各问提炼出的"精确归约"型性质（利用凸性/对称性做归约的典型先例）：
- 每项：`命题 N：<一句话陈述>`，附 `归约对象 → 归约后的有限特征集` 的映射说明。
- 目的：给 deep_formalizer 提供可检索的"凸性/对称性归约"先例，供下一题复用。

### 3.5 跨问递进承接句（每问开头一句）
每问开头必须有一句递进承接："问题 X 在问题 Y 的基础上，从 …… 提升到了 ……"，让评委不看目录也感到递进链。在蓝图 3.1 每章标题下预留承接句字段。

### 3.6 结构自检表（写作前必须过）
逐项打勾，凡未勾选的即为写作时必填项：
```
[ ] 章节树完整（章节数 = 问题数 + 首末两章）
[ ] 每问子结构六项齐全（模型/求解/结果/策略规律/亮点/判据示意）
[ ] 参考文献席已填（真实文献 2-4 条；无则标注待主线程补充）
[ ] 定理/命题清单已列（至少 1 条归约类性质，确无则注明"已尝试、不适用"）
[ ] 每问开头递进承接句已写
[ ] 匿名合规（无学校/姓名/赛区；全文"本文"不用"我们"）
```

## 4. 蓝图 → 写作 → 结构审校 三段流

```
[阶段 5a] 建模报告 (modeling_report.md) 审批通过
        ↓
[阶段 5b-1] paper_planner 生成 blueprints/paper_blueprint.md  ← 本规范格式
        ↓（蓝图经人/审阅确认）
[阶段 5b-2] chapter_writer 逐段写 sections/*.tex，每段对照蓝图子结构
        ↓
[阶段 5b-3] paper_structural_reviewer 对照蓝图逐项核对兑现度
        ↓
[阶段 5c] Tectonic 编译 paper.pdf + 质量清单复核
```

蓝图是装配图，章节是成品，结构审校是验收。三者解耦，任何一处缺结构都能被定位。
