# 论文去 AI 味规范（no_ai_style）

> 2026-08-29 新增。用途：数学建模竞赛论文正文的**去 AI 痕迹改写规则库 + 验证手段**。
> 来源：对比了三个开源 humanizer（A=humanizer-academic-zh 25类语义模式 / B=say-it-human 19维浓度分级 / C=humanize-mba-text 三维协同+句长CV）后，择优整合。
> 定位：**A 的词典做改写规则 + C 的量化自检做验证 + B 的防误伤红线**。**不吸收 B 的口语化改写倾向**（对竞赛论文有害）。

---

## 0. 总原则（先读这条）

- **目标是去掉 AI 痕迹，不是把论文改口语**。这是竞赛学术论文，文风要**严谨平实**。
- **保持术语统一**：同一概念全程用同一术语（类别覆盖 / 类别结构 / A/B/C类），不刻意同义替换。
- **保留所有数学表达与数值**：n*、m³、命题、字典序、18→29 这类是模型结论，不是 AI 味，**绝不能删**。去 AI 味只针对：方括号标签标题、说教式/升华过渡、括注堆、过度命题化、套话。
- **数据的可复现性**：去 AI 味后不得改动任何数值、结论、模型名。

---

## 1. 改写规则库（A：25 类语义模式，适配竞赛论文版）

以下每一条是一个 AI 痕迹类别 + 改写处方。改写时对照命中，命中即改。

### 1.1 表达类
| # | AI 痕迹 | 改写处方 |
|---|---------|---------|
| 1 | **过度强调意义**：至关重要、发挥了关键作用、凸显了重要性、反映了更广泛的、标志着、关键转折点 | 删或弱化，改具体克制描述 |
| 2 | **「基于/依据 XX 理论」起笔**：一段以理论名开头 | 现象先行，理论名移到中/后 |
| 3 | **段末套路**：此案例印证、从中可以看出、综上所述、由此可见、不难发现 | 删，换自然过渡 |
| 4 | **被动分析套话**：该处理体现了、该设计基于 | 改直接说明 |
| 5 | **模板化问题陈述**：面临的核心问题是、核心挑战在于 | 换具体表述 |
| 6 | **抽象动词假深度**：凸显了、体现了、彰显了、促进了、展示了 | 删或改明确动词 |
| 7 | **推销广告化**：充满活力的、深刻的、开创性的 | 中性精确 |
| 8 | **模糊归因**：专家认为、研究表明、有观点认为 | 删或改直接陈述 |
| 9 | **公式化挑战展望**：尽管面临挑战、未来展望、具有重要意义、为…提供新思路 | 删空泛升华 |

### 1.2 语言类
| # | AI 痕迹 | 改写处方 |
|---|---------|---------|
| 10 | **中文 AI 高频词**：深刻揭示了→说明/表明；具有重要意义→直接说意义；综合运用→结合使用；不可或缺→必要/关键；至关重要的→关键的 | 替换为克制词 |
| 11 | **系动词回避**：作为…的重要载体/扮演着…的角色 | 用「是/有」 |
| 12 | **高度对称并列三组**：首先/其次/再次 | 打破 |
| 13 | **过度对仗排比** | 只留核心一项 |
| 14 | **刻意同义替换** | 保持术语统一 |
| 15 | **否定式排比**：不仅仅是…更是… | 直接陈述 |
| 16 | **虚假范围**：从 X 到 Y 硬凑 | 确保一致或具体 |
| 17 | **破折号滥用** | 段内不超 2 处 |
| 18 | **粗体滥用** | 正文不加粗（图题/表题除外） |

### 1.3 风格类
| # | AI 痕迹 | 改写处方 |
|---|---------|---------|
| 19 | **内联标题纵向列表**：[策略规律]/[亮点] 这类方括号标签 | 改连贯段落，标签并入正文小标题 |
| 20 | **表情符号** | 删除 |
| 21 | **填充短语**：为了实现这一目标→为此；值得注意的是→数据显示→数据显示；不难发现两者之间存在→两者之间存在；需要指出的是该方法→该方法 | 删冗余填充 |
| 22 | **过度对冲** | 删冗余限定（保留必要学术审慎） |
| 23 | **协作式沟通痕迹**：希望有帮助/这里是一份 | 删 |
| 24 | **知识截止免责**：截至我的知识/作为 AI | 删（正常时间/统计范围说明保留） |
| 25 | **谄媚语气** | 删过度正面 |

## 2. 验证手段（C：句长 CV 量化自检）

改写完成后**必须量化验证**，不靠感觉。用句长 CV（变异系数）确认 AI 味是否真的降了。

### 2.1 句长 CV 检测
- **原理**：AI 文本句子长度更均匀（CV 低）；人类写作长短句交错（CV 高）。
- **检测方法**：
  1. 把段落按中文句号/分号/问号切成句子；
  2. 统计每句字数（按字符数，不含标点）；
  3. 算标准差 / 均值 = **句长 CV**。
- **判定**：`CV ≥ 0.30` 正常（长短句有起伏）；`CV < 0.25` 偏 AI 味，需打散句式（加短句、拆长句）。
- **用脚本自动跑**（见 §4 `check_ai_style.py`），避免人工数。

### 2.2 术语一致自检
- 全文同一概念用同一术语，检索关键概念词计数，若同概念出现 ≥2 种不同叫法 → 统一。

### 2.3 段落长度均匀度
- 相邻段落长度太接近（段落平均长度 CV < 0.20）也偏 AI。适当合并/拆分段落，制造长短错落。

## 3. 防误伤红线（B：看密度不看出现 + 学术不误伤）

**这一条最重要，是兜底红线。** 改过头会毁掉学术论文。

### 3.1 看密度不看出现
- 某表达**单次出现**不算 AI 味，**200 字内反复 3 次以上**才算。
- 排比/对仗/成语，真人写作也在用，单次不算。避免过度修正。

### 3.2 学术文体别误伤
- 竞赛论文的规范表达（命题、引理、定理、"由上文可知"）**不是 AI 味**，不要删。
- 必要的数学符号、单位、模型名一律保留。
- **宁可少删，不可误删**——删错一个数值/命题比留一句套话严重得多。

### 3.3 数据/结论不可改动
- 去 AI 味的**唯一可改的东西是措辞**。数值、单位、模型结论、文献引用，一律保持原样。
- 改完必须**重新校对一遍所有数字**是否与原文一致。

## 4. 落地工具：`check_ai_style.py`

在 `scripts/` 下提供脚本，自动做「AI 痕迹词扫描 + 句长 CV 量化」。

**用法**：
```bash
python scripts/check_ai_style.py .modeling/manuscript/sections/02_problem1.tex
```

**功能**：
1. 扫描 AI 痕迹词（复用 §1 的警惕词表）；
2. 统计句长 CV；
3. 输出命中清单 + CV 值 + 是否通过判定，供 chapter_writer 修改后复检。

---

## 5. 与其他文件的关系

- **chapter_writer.md**：写作完成、**编译前**必须跑一次 `check_ai_style.py`，命中清单 + CV < 0.25 → 回改；全清 + CV ≥ 0.30 → 放行。
- **paper_structural_reviewer.md**：结构审校加一条**「去 AI 味验收」**——检测方括号标签/套话/括注堆/口语化过度/说教，命中即回退。
- **paper_figures.md**：只管配图配色，与本文正交；两者在「论文观感对齐 A196」这一个大目标下并行。
